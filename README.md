# Sparks Website - WEDE5020 POE

## Project Description
This is a tourism and outdoor activities website developed for adventurous experiences. 
The website showcases hiking, zipline, climbing and buffet services with 12 responsive HTML pages.

**Live Site:** https://moengapp.github.io/sparkswebsite/
**Repository:** https://github.com/moengapp/sparkswebsite

## Website Structure (12 Pages)
1. index.html - Home
2. about.html - About Us
3. contact.html - contact us
4. individual.html - individual page
5. fees.html - feespage
6. overview.html - overiew page
7. packages.html - packages page
8. rate.html - rate us
9. gallery.html- gallery tour
10. faq.html- frequently asked questions
11. booking.html - bookings page
12. testimonials.html - testimonial page
   

## Technologies Used
- HTML5
- CSS3 (css/style.css)
- Responsive Design
