Project Overview

Adventure Escape SA Website

This overview explains the structure, purpose and features of the Adventure Escape SA website built for WEDE5020 POE.

1. Purpose

To promote outdoor adventure experiences in South Africa and provide clear information about packages, fees, and bookings.

2. Site Structure

  • index.html - Home / Hero / Call to Action
  • about.html - History, Vision, Mission, Goals
  • fees.html - 7 Packages + Fee Calculator (R750 / R1500)
  • contact.html - Contact Form + Details
  • style.css - Global styling

3. Key Features

  • Responsive design (mobile + desktop)
  • Sticky navigation with active page highlight
  • Fee calculator with JavaScript (fees.html)
  • Contact form validation
  • Modern brown/beige color palette (#1b0d07 / #f7f3ee)

4. Technologies

HTML5, CSS3 (variables, flex, grid), Vanilla JavaScript. No frameworks. Images from /images folder.

5. GitHub Repo

Repo: https://github.com/moengapp/moeng-ST10502191WEDE5020POE

All pages validated and linked. Logo in header links back to Home.
